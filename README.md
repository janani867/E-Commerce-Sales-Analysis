# E-Commerce Sales Analysis

## Project Overview

This project analyzes an e-commerce sales dataset to understand sales performance, customer purchasing behavior, product category performance, payment preferences, discount patterns, and regional sales trends.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib

## Dataset

The analysis is performed using an Amazon e-commerce sales dataset.

## Analysis

The project explores sales trends, customer behavior, product performance, payment methods, discounts, and regional sales patterns.

## Project Files

- `Ecommerce_Sales_Analysis.ipynb` — Jupyter Notebook containing the complete analysis.
- `amazon_sales_dataset.csv` — Dataset used for the analysis.
